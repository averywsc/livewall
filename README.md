# Live Wallpaper

A free live wallpaper app for Windows 10 and 11. Set a video, GIF, or image as your wallpaper, add overlays, play background music, and save your setups as scenes. It runs completely offline with no account, no ads, no telemetry, and no store.

MIT, see `LICENSE`. Third-party components: see `THIRD_PARTY.md`. The libmpv DLL must be an LGPL build to keep the whole app MIT.
